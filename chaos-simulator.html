Scientific & Mathematical Foundations

This simulator implements raw physical equations integrated using high-accuracy numerical methods, juxtaposed against a custom multi-layer artificial neural network written from first principles.

Lagrangian Formulation of the Double Pendulum

A simple pendulum has a single degree of freedom. A double pendulum has two, represented by the angles $\theta_1$ and $\theta_2$ of the rods relative to the vertical axis. The position coordinates of the two masses are:

$$x_1 = L_1 \sin\theta_1, \quad y_1 = -L_1 \cos\theta_1$$ $$x_2 = L_1 \sin\theta_1 + L_2 \sin\theta_2, \quad y_2 = -L_1 \cos\theta_1 - L_2 \cos\theta_2$$

The total Kinetic Energy ($T$) and Potential Energy ($V$) of the system are:

$$T = \frac{1}{2} m_1 v_1^2 + \frac{1}{2} m_2 v_2^2 = \frac{1}{2} m_1 L_1^2 \dot{\theta}_1^2 + \frac{1}{2} m_2 \left[ L_1^2 \dot{\theta}_1^2 + L_2^2 \dot{\theta}_2^2 + 2 L_1 L_2 \dot{\theta}_1 \dot{\theta}_2 \cos(\theta_1 - \theta_2) \right]$$ $$V = -(m_1 + m_2)g L_1 \cos\theta_1 - m_2 g L_2 \cos\theta_2$$

Using the Lagrangian $L = T - V$ and applying the Euler-Lagrange equations $\frac{d}{dt}\left(\frac{\partial L}{\partial \dot{\theta}_i}\right) - \frac{\partial L}{\partial \theta_i} = 0$, we solve for the angular accelerations $\ddot{\theta}_1$ and $\ddot{\theta}_2$:

$$\ddot{\theta}_1 = \frac{-g(2m_1 + m_2)\sin\theta_1 - m_2 g \sin(\theta_1 - 2\theta_2) - 2\sin(\theta_1 - \theta_2)m_2\left(\dot{\theta}_2^2 L_2 + \dot{\theta}_1^2 L_1 \cos(\theta_1 - \theta_2)\right)}{L_1 \left(2m_1 + m_2 - m_2 \cos(2\theta_1 - 2\theta_2)\right)}$$ $$\ddot{\theta}_2 = \frac{2\sin(\theta_1 - \theta_2)\left(\dot{\theta}_1^2 L_1(m_1 + m_2) + g(m_1 + m_2)\cos\theta_1 + \dot{\theta}_2^2 L_2 m_2 \cos(\theta_1 - \theta_2)\right)}{L_2 \left(2m_1 + m_2 - m_2 \cos(2\theta_1 - 2\theta_2)\right)}$$

Chaos Insight: The equations are highly coupled and non-linear. The system is extremely sensitive to initial conditions. A change in starting angle of even $0.0001$ radians leads to exponential divergence of the orbits (characterized by a positive Lyapunov exponent).

The Lorenz Dynamical System

Developed by meteorologist Edward Lorenz in 1963, the Lorenz system represents a highly simplified model of atmospheric convection. It is a set of three coupled, non-linear ordinary differential equations:

$$\frac{dx}{dt} = \sigma (y - x)$$ $$\frac{dy}{dt} = x (\rho - z) - y$$ $$\frac{dz}{dt} = xy - \beta z$$

Where parameters describe physical properties:

  • $\sigma$ (Sigma): Prandtl number representing fluid viscosity.
  • $\rho$ (Rho): Rayleigh number representing heat convection driving force. (At $\rho = 28$, chaos emerges).
  • $\beta$ (Beta): Geometric dimension ratio of the convection cells.

Butterfly Effect: Plotting the trajectories in 3D $(x,y,z)$ reveals a fractal shape known as the Lorenz Attractor. The system cycles infinitely between two wings without ever intersecting its own path, creating a butterfly-wing visual mapping.

Runge-Kutta 4th Order (RK4) Numerical Integration

Standard Euler integration ($x_{t+1} = x_t + v_t \cdot dt$) accumulates error quickly ($O(dt)$), causing physical systems to violate conservation of energy and drift rapidly. This simulator uses the **Runge-Kutta 4th Order (RK4)** integration method, which has an error of $O(dt^4)$.

For any system defined by a differential equation $\frac{d\vec{w}}{dt} = f(t, \vec{w})$, RK4 computes four trial slopes at different increments within the time-step $dt$:

$$\vec{k}_1 = f\left(t_n, \vec{w}_n\right)$$ $$\vec{k}_2 = f\left(t_n + \frac{dt}{2}, \vec{w}_n + \frac{dt}{2} \vec{k}_1\right)$$ $$\vec{k}_3 = f\left(t_n + \frac{dt}{2}, \vec{w}_n + \frac{dt}{2} \vec{k}_2\right)$$ $$\vec{k}_4 = f\left(t_n + dt, \vec{w}_n + dt \vec{k}_3\right)$$

The state is updated using a weighted average of these four slopes, giving higher weight to the midpoint values:

$$\vec{w}_{n+1} = \vec{w}_n + \frac{dt}{6} \left(\vec{k}_1 + 2\vec{k}_2 + 2\vec{k}_3 + \vec{k}_4\right)$$

Deep Learning from Scratch in JavaScript

The neural network here is implemented from first-principles matrix math. It predicts the future state of a chaotic system $\vec{s}_{t+1}$ based on current state parameters $\vec{s}_t = [q_1, q_2, p_1, p_2]$.

1. Feed-Forward Process

For any layer $l$, the pre-activation vector $z^{[l]}$ and activation vector $a^{[l]}$ are calculated as:

$$z^{[l]} = W^{[l]} a^{[l-1]} + b^{[l]}$$ $$a^{[l]} = g(z^{[l]})$$

Where $W^{[l]}$ is the weight matrix, $b^{[l]}$ is the bias vector, and $g(x)$ is the activation function. We implement both the hyperbolic tangent ($\tanh$) and ReLU activations:

$$\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}, \quad \text{ReLU}(x) = \max(0, x)$$

2. Loss Evaluation

To measure prediction accuracy, we compute the Mean Squared Error (MSE) loss across a batch of $N$ target states:

$$\mathcal{L} = \frac{1}{2N} \sum_{i=1}^N \|\hat{y}^{(i)} - y^{(i)}\|^2$$

3. Backpropagation (The Chain Rule)

To optimize the weights, we calculate the gradients of the loss function with respect to weights and biases by backpropagating the error using the calculus chain rule:

$$\delta^{[L]} = \frac{\partial \mathcal{L}}{\partial z^{[L]}} = (\hat{y} - y) \odot g'(z^{[L]})$$ $$\delta^{[l]} = \left( (W^{[l+1]})^T \delta^{[l+1]} \right) \odot g'(z^{[l]})$$

The gradients are used to update the weights and biases using gradient descent with learning rate $\eta$:

$$W^{[l]} \leftarrow W^{[l]} - \eta \frac{\partial \mathcal{L}}{\partial W^{[l]}}, \quad \text{where } \frac{\partial \mathcal{L}}{\partial W^{[l]}} = \delta^{[l]} (a^{[l-1]})^T$$ $$b^{[l]} \leftarrow b^{[l]} - \eta \delta^{[l]}$$

Gravitational Obstacles: External Force Fields

Clicking on the simulation canvas places a gravitational attractor — a massive body that exerts a gravitational pull on both pendulum bobs, modifying their trajectories in real time. Drag to reposition; right-click to remove.

Force Vector on Each Bob

For an attractor at position $\mathbf{P}$ with lumped strength $G \cdot M$, the gravitational force on bob $i$ at position $\mathbf{r}_i$ is:

$$\mathbf{F}_i = \frac{G \cdot M \cdot m_i}{|\mathbf{r}_i - \mathbf{P}|^2} \hat{r}_i, \quad \hat{r}_i = \frac{\mathbf{P} - \mathbf{r}_i}{|\mathbf{P} - \mathbf{r}_i|}$$

Generalised Torques via Virtual Work

Because the pendulum is constrained, we cannot apply $\mathbf{F}_i$ directly to the joint angles. Instead, the principle of virtual work converts the Cartesian force into a generalised torque on joint $j$:

$$\tau_j^{(i)} = \mathbf{F}_i \cdot \frac{\partial \mathbf{r}_i}{\partial \theta_j}$$

The partial derivatives of the bob positions with respect to the generalised coordinates are:

$$\frac{\partial \mathbf{r}_1}{\partial \theta_1} = \begin{pmatrix} L_1 \cos\theta_1 \\ -L_1 \sin\theta_1 \end{pmatrix}, \quad \frac{\partial \mathbf{r}_2}{\partial \theta_2} = \begin{pmatrix} L_2 \cos\theta_2 \\ -L_2 \sin\theta_2 \end{pmatrix}$$

These torques $\tau_1, \tau_2$ are added directly into the Lagrangian angular acceleration numerators, coupling the external field seamlessly into the existing RK4 integration.

AI Awareness of the Environment

The neural network input dimension has been extended from 6 to 8 features. The two additional features encode the attractor position normalised to $[-1, 1]$:

$$\vec{s}_t = [\sin\theta_1,\, \sin\theta_2,\, \cos\theta_1,\, \cos\theta_2,\, \hat{\omega}_1,\, \hat{\omega}_2,\, \tilde{x}_{\text{att}},\, \tilde{y}_{\text{att}}]$$

Physics Insight: Moving the attractor after training invalidates the learned dynamics. The loss spikes and re-decreases as the network adapts to the new force field, demonstrating online learning in a non-stationary environment.
